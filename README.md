# 📊 Data Cleaning & Visualization Project

## 📌 Project Overview
This project focuses on cleaning, processing, and analyzing a student performance dataset to extract meaningful insights using data visualization techniques. The objective is to demonstrate core data analysis skills including data preprocessing, exploratory data analysis (EDA), and storytelling through visualizations.

---

## 🎯 Objective
To transform raw student performance data into actionable insights by applying data cleaning techniques and visual analytics.

---

## 📂 Dataset Description
The dataset contains **1000 student records** with **8 features**, including:

- Gender  
- Race/Ethnicity  
- Parental Level of Education  
- Lunch Type  
- Test Preparation Course  
- Math Score  
- Reading Score  
- Writing Score  

This dataset is widely used for understanding how demographic and socio-economic factors influence academic performance.

---

## 🛠️ Technology Stack
- **Programming Language:** Python  
- **Libraries Used:**  
  - Pandas (Data manipulation)  
  - NumPy (Numerical operations)  
  - Matplotlib (Data visualization)  
  - Seaborn (Statistical visualization)  

---

## 🔧 Data Preprocessing
The following data cleaning steps were performed:

- Verified and confirmed absence of missing values  
- Identified and removed duplicate records  
- Standardized column names for consistency  
- Engineered a new feature: `average_score` to represent overall performance  

---

## 📊 Exploratory Data Analysis & Insights

Key findings from the analysis include:

- 📌 Majority of students scored between **60–80**, indicating average performance distribution  
- 📌 Students who completed the **test preparation course performed significantly better**  
- 📌 **Female students slightly outperformed male students** in overall scores  
- 📌 Strong positive correlation observed between **math, reading, and writing scores**  

---

## 📈 Visualizations Included
- Distribution Plot (Average Score)
- Box Plot (Gender vs Performance)
- Bar Plot (Test Preparation Impact)
- Correlation Heatmap
- Count Plot (Parental Education Distribution)

---

## 🧠 Conclusion
The analysis highlights the importance of preparation and background factors in influencing student performance. Effective data cleaning and visualization techniques enabled the identification of meaningful patterns and relationships within the dataset.
